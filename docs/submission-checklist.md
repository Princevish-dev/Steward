# Submission checklist

- [ ] Repository is public.
- [ ] MIT license file is visible and GitHub About shows MIT.
- [ ] Public YouTube demo is in English and under 3:00.
- [ ] Demo URL is live and opens the dashboard.
- [ ] Demo login and PayPal Sandbox buyer test credentials are supplied privately
  to judges or in the Devpost field; never commit them.
- [ ] AI tools and model usage are listed in README and Devpost text.
- [ ] PayPal Sandbox, Channel3 live/fixture behavior, and simulated fulfilment are
  labelled in the UI and documentation.
- [ ] README contains quick start, screenshots, API maps, safety model, MCP
  configuration, tests, limitations, and license.
- [ ] CI is green on the submission commit.
